## Quick Setup

1. Add `@phasevueui/nuxt-module` dependency to your project

```bash
npx nuxi@latest module add phasevue
```

2. Add `@phasevueui/nuxt-module` to the `modules` section of `nuxt.config.{ts,js}`

```js
{
    modules: ['@phasevueui/nuxt-module'];
}
```

That's it! You can now use `@phasevueui/nuxt-module` in your Nuxt app ✨

# PhaseVue

PhaseVue is a Vue UI component library for building modern, accessible web applications.

This repository is the beginning of the PhaseVue fork. It provides a familiar component API, theming support, and the tooling needed to build and document Vue applications.

## Development

Install the dependencies and start the showcase application:

```bash
pnpm install
pnpm dev
```

PhaseVue is released under the MIT license.
